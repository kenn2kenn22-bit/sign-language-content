# SignLearn Content

Public content packs for the SignLearn mobile application.

The first planned packs are **LSF for France** and **LSE for Spain**. Arabic is intentionally postponed until a specific country or Deaf signing community is confirmed; there is no single universal Arabic sign language to publish under one generic label.

This repository contains only final media, manifests, translations and attribution records intended to be fetched by the app without authentication. No sign-language video has been published yet.
