# SignLearn Content

Public content packs for the SignLearn mobile application.

This repository contains only final media, manifests, translations and attribution records intended to be fetched by the app without authentication.

## Current status

The repository is initialized. No sign-language media is published yet. Content must not be added until its source, language, license, modification permission and commercial-use status have been checked.
