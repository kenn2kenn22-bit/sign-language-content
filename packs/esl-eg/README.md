# ESL — Egypt

Pack reserved for Egyptian Sign Language in Egypt. This pack is not a generic Arabic sign-language pack and must not be presented as universal across Arabic-speaking countries. No media has been published yet.

The Mendeley Egyptian Sign Language dataset is a candidate source under CC BY 4.0, but rights-to-image, consent and contributor review are still required before any media is copied here. See [SOURCE_REVIEW.md](SOURCE_REVIEW.md).
