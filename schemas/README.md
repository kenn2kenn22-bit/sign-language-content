# Provenance des médias SignLearn

`asset-provenance.schema.json` décrit les métadonnées minimales à conserver pour un futur signe ou média : source exacte, version, checksum, licence, usage commercial, consentement à l’image, dérivés d’animation, éléments de tiers et relecture linguistique.

Le fichier `asset-provenance.example.json` est un exemple volontairement non approuvé. Ses valeurs `false`, son statut `needs-correction` et son attribution provisoire montrent qu’un enregistrement de provenance ne constitue pas automatiquement une autorisation.

Avant qu’un média soit ajouté dans `packs/`, toutes les preuves doivent être conservées dans le dépôt privé ou un stockage sécurisé. Le dépôt public ne doit contenir que les informations nécessaires à l’attribution et au contrôle de provenance, sans contrats ni données personnelles des signants.
